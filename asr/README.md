# Zachovaná verze ASR

Původní web a repozitář jsou nezávislé a nemění se:

- [Web ASR](https://nabiknab-eng.github.io/ceres-asr-temperature-atlas/)
- [Zdrojový repozitář ASR](https://github.com/nabiknab-eng/ceres-asr-temperature-atlas)

Zde jsou pouze nezměněné podpůrné výpočetní skripty potřebné k reprodukci CERES. Při kompletním přepočtu doplňte původní soubory podle hlavního README. Úplná místní kopie ASR byla při tvorbě CERES ověřena kontrolními součty; protokol je v `asr_version_lock.json`.
