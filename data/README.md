# Plné výpočtové hodnoty

[Stáhnout `ceres_anomalies.nc` ve float64](https://github.com/nabiknab-eng/ceres/releases/download/v1.0.0/ceres_anomalies.nc). Soubor obsahuje šest veličin, jejich neměnné reference 2001–2025 a skupiny `rolling`, `annual`, `fiveyear` s časovými hranicemi.

Pro prohlížení a export MP4 se používají úplné lokální float32 bloky v `viewer/`; větší NetCDF není k těmto činnostem potřeba. `projection.bin.gz` je shodná projekční tabulka Pythonu a HTML. Reprodukční postup a původní vstupy popisuje hlavní README.
